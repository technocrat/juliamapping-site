# juliamapping-site

Static site for *Julia Mapping: A Practical Guide* (JuliaMapping.com), published by Wm Playfair Press.

- `build.py` writes `index.html` and `gallery.html` from `figures.json`.
- `img/full` and `img/thumb` are web-sized copies of the book's figures (WebP).
- Independent guide. Not affiliated with the Julia project.

Deploy: Cloudflare Pages, no build command, output directory `/`.
